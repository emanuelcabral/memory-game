# 🧠 Memory Game - Juego de Memoria Visual 🃏

¡Pon a prueba tu memoria y agudiza tus reflejos! Encuentra todos los pares en el menor tiempo y con la menor cantidad de movimientos.  

Este juego está hecho con **HTML, CSS y JavaScript**, e incluye **sonidos, animaciones, temporizador y contador de movimientos**, ofreciendo una experiencia interactiva y profesional.

## 🎮 Cómo jugar

1. Abre `index.html` en tu navegador.  
2. Haz clic en cualquier carta para voltearla.  
3. Encuentra los **pares idénticos** antes de terminar el tiempo o movimientos.  
4. El juego termina cuando **todos los pares hayan sido encontrados**.  
5. Haz clic en **Reiniciar** para empezar otra partida.

---

## ⚡ Funcionalidades principales

- 🧩 Tablero **4x4** con 8 pares de cartas  
- ⏱ **Temporizador** para medir tu tiempo  
- 🔢 **Contador de movimientos**  
- 🔊 **Efectos de sonido** al voltear carta, hacer match y ganar  
- 🎉 Mensajes dinámicos de victoria  
- 🔁 Botón de **Reiniciar juego**  
- 🎨 Animaciones al voltear cartas y feedback visual al hacer match
